# React 학습 정리

주제를 하나씩 잡고 작은 앱으로 만들어보는 방식으로 정리했습니다.

| 폴더 | 주제 |
| :--- | :--- |
| [`todo-app`](./todo-app) | 컴포넌트 분리와 상태 끌어올리기 |
| [`api-integrate`](./api-integrate) | API 연동 — 로딩·에러·성공 세 상태를 다루는 패턴 |
| [`router-tutorial`](./router-tutorial) | 라우팅 기본 |
| [`styled-components`](./styled-components) | CSS-in-JS로 스타일 컴포넌트화 |
| [`bolg-react`](./bolg-react) | 블로그 형태로 앞의 내용 조합 |
| [`motorcycle-drive`](./motorcycle-drive) | 연습용 프로젝트 |
| [`리액트를 다루는 기술`](./리액트를%20다루는%20기술) | 책을 따라가며 작성한 코드 |

노트: [`react-router-dom.md`](./react-router-dom.md)

각 폴더에서 `yarn install && yarn start`로 실행합니다.
